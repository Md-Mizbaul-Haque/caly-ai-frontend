# Caly AI Tracker UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build tracker-native 4-tab calorie UI in Expo using delivery-feel tokens only.

**Architecture:** Local-first v1 with `useState` tab shell in `App.js`, NativeWind styling from single `tokens.js`, mock meal store ready for backend `POST /api/meals/estimate` later. No expo-router, no new native deps to stay Expo Go compatible.

**Tech Stack:** Expo SDK 57, React 19.2.3, React Native 0.86.3, NativeWind 4.2.7, tailwindcss 3.4.17

**Spec:** `docs/superpowers/specs/2026-09-29-caly-ui-design.md`

## Global Constraints

- Expo SDK ~57.0.25 — do not add native libs requiring dev-build in v1, stay Expo Go compatible.
- Portrait only per `app.json`, `userInterfaceStyle` light.
- Styling via NativeWind `className` + `tailwind.config.js` extend from tokens — no hardcoded hex in screens.
- No `expo-router` in v1 — tab state via `useState` in `App.js`.
- Backend routes do not exist yet (`src/index.js` TODO) — v1 is local-first with mock data, API-ready only.
- Run `npx expo-doctor` clean before declaring done.
- Never hand-edit `ios/`/`android/` — CNG only via `app.json`.

## Review Focus

- Empty daily log renders ring at 0% with EmptyState CTA, not blank or NaN.
- Manual log with kcal <=0 or empty name is rejected with inline hint and Save stays disabled.
- Over-goal day clamps ring to 100% and shows red over-label, does not overflow layout.
- `EXPO_PUBLIC_API_URL` missing still loads app with mock data and shows API URL placeholder in Profile.
- Rapid add-then-delete of meals keeps totals consistent with no negative kcal display.

// src/components/ui/ProgressRing.js
import { View, Text } from 'react-native';
export default function ProgressRing({ eaten, goal }) {
  const safeGoal = Math.max(goal, 1);
  const pct = Math.min(100, Math.round((Math.max(eaten, 0) / safeGoal) * 100));
  const remaining = goal - eaten;
  return (
    <View className="items-center justify-center py-4">
      <Text className="text-4xl font-bold text-ink">{pct}%</Text>
      <Text className="text-muted mt-1">{Math.max(eaten,0)} / {goal} kcal</Text>
      <Text className={remaining < 0 ? 'text-red-500 font-bold mt-1' : 'text-success font-bold mt-1'}>
        {remaining < 0 ? `${Math.abs(remaining)} over` : `${remaining} left`}
      </Text>
    </View>
  );
}
```

// src/utils/totals.js
function calcTotals(meals, goal) {
  const eaten = meals.reduce((s, m) => s + (Number(m.kcal) || 0), 0);
  const protein = meals.reduce((s, m) => s + (Number(m.protein) || 0), 0);
  const carbs = meals.reduce((s, m) => s + (Number(m.carbs) || 0), 0);
  const fat = meals.reduce((s, m) => s + (Number(m.fat) || 0), 0);
  const safeGoal = Math.max(Number(goal) || 2000, 1);
  const pct = Math.min(100, Math.round((Math.max(eaten, 0) / safeGoal) * 100));
  return { eaten: Math.max(eaten, 0), remaining: goal - eaten, pct, protein, carbs, fat };
}
module.exports = { calcTotals };
```

// lib/api.js — append:
export async function apiPost(path, body) {
  const res = await fetch(`${API_URL}${path}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body),
  });
  if (!res.ok) throw new Error(`POST ${path} failed: ${res.status}`);
  return res.json();
}
